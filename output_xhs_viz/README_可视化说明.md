# 小红书「AI科研」搜索结果数据可视化说明

> 数据来源：`data/xhs/jsonl/search_contents_2026-10-26.jsonl`（笔记 80 条）、`search_comments_2026-10-26.jsonl`（评论 749 条）
> 可视化脚本：`xhs_visualize.py`　输出目录：`output_xhs_viz/`

---

## 一、数据概览

| 数据集 | 记录数 | 说明 |
|---|---|---|
| 笔记（contents） | 80 | 4 个关键词各 20 条：AI科研 / 科研自动化 / 科研智能体 / 科研工作流 |
| 评论（comments） | 749 | 覆盖 69 篇笔记，均为一级评论（无二级回复） |

- 发布时间跨度：2025-07-04 → 2026-10-19；评论跨度至 2026-10-26。
- 整体互动：点赞 21.0 万、收藏 24.2 万、评论 2.0 万、分享 9.3 万（笔记侧）；评论获赞合计 12.1 万。

## 二、字段含义与结构

### 1. 笔记表 `search_contents_2026-10-26.jsonl`（每行一篇笔记）

| 字段 | 类型 | 含义 |
|---|---|---|
| `note_id` | string | 笔记唯一 ID |
| `type` | string | 笔记类型：`normal`（图文）/ `video`（视频） |
| `title` | string | 笔记标题 |
| `desc` | string | 正文描述（含话题标签文本） |
| `video_url` | string | 视频地址，图文笔记为空 |
| `time` | int | 发布时间戳（毫秒） |
| `last_update_time` | int | 最后更新时间戳（毫秒） |
| `creator_hash` | string | 创作者哈希标识（脱敏） |
| `nickname` | string | 作者昵称（部分星号脱敏） |
| `liked_count` | string | 点赞数，可能带「万」单位，如 `1.3万` |
| `collected_count` | string | 收藏数，同上 |
| `comment_count` | string | 评论数，同上 |
| `share_count` | string | 分享数，同上 |
| `image_list` | string | 图片 URL 列表（逗号分隔） |
| `tag_list` | string | 话题标签（逗号分隔，部分有） |
| `note_url` | string | 笔记详情页链接 |
| `source_keyword` | string | 该笔记来自哪个搜索关键词 |
| `xsec_token` | string | 访问安全令牌 |

> 关键清洗点：四个互动字段是**字符串**且含「万」单位，需先解析成数值才能统计。

### 2. 评论表 `search_comments_2026-10-26.jsonl`（每行一条评论）

| 字段 | 类型 | 含义 |
|---|---|---|
| `comment_id` | string | 评论唯一 ID |
| `create_time` | int | 评论发布时间戳（毫秒） |
| `note_id` | string | 所属笔记 ID（可关联笔记表） |
| `content` | string | 评论正文 |
| `creator_hash` | string | 评论者哈希标识 |
| `nickname` | string | 评论者昵称 |
| `sub_comment_count` | string | 该评论下的子评论数（楼中楼数量） |
| `pictures` | string | 评论图片，通常为空 |
| `parent_comment_id` | string | 父评论 ID；为空表示一级评论（本数据全为空） |
| `last_modify_ts` | int | 最后修改时间戳 |
| `like_count` | string | 评论获赞数，可能带「万」单位 |

### 3. 数据结构关系

```
笔记 (80)  1 ──── N  评论 (749)      # 通过 note_id 关联
笔记.source_keyword ──> 搜索关键词（4 类）
笔记.type ──> 图文 / 视频
评论.parent_comment_id ──> 一级评论（本数据无二级回复）
```

## 三、图表选型与说明

根据两份数据的特征（80 条分类型笔记 + 749 条长尾评论，数值存在「万」级跨度与明显离群），共选取 **8 张图，覆盖 6 类分析视角**：

| # | 图表文件 | 图表类型 | 为什么选它 | 看什么 |
|---|---|---|---|---|
| 1 | `01_笔记类型构成.png` | 环形图（Pie） | 类型只有两类，关注占比 | 图文 88.8% / 视频 11.2%，样本以图文为主 |
| 2 | `02_关键词平均互动对比.png` | 分组柱状图 | 4 关键词 × 4 指标的多维对比 | AI科研 组点赞/收藏最高；科研智能体整体互动最低 |
| 3 | `03_Top10高赞笔记.png` | 水平条形图 | 排名类数据，长标题需横向排布 | Top1 为「扒完NS事件…」1.3 万赞 |
| 4 | `04_互动指标箱线图.png` | 箱线图 | 展示四项指标分布、中位数与离群点 | 收藏 > 点赞 > 分享 > 评论；点赞/收藏离群值显著 |
| 5 | `05_评论点赞分布.png` | 对数直方图 | 评论获赞跨 0~2.9 万，需对数分箱 | 高度右偏，中位数仅 1，少数评论吸走大部分赞 |
| 6 | `06_Top15评论数笔记.png` | 水平条形图 | 结合 note_id 聚合评论数排名 | 「上交大：Claude Code…」40 条评论居首 |
| 7 | `07_评论时间趋势.png` | 折线+面积图 | 时间序列，看讨论热度走势 | 2026-03、2026-10 出现两个明显高峰 |
| 8 | `08_点赞评论相关性.png` | 散点图+拟合线 | 两个连续变量的相关性 | 正相关（r≈0.68），点赞越多评论越多 |

> 所有图表均包含**标题、坐标轴标签、图例**（环形图/箱线图的图例或刻度即类别说明），并在必要处标注单位与离群点。

## 四、关键发现

1. **内容以图文为主**：80 篇中图文 71 篇（88.8%），视频仅 9 篇。
2. **AI科研关键词互动最强**：平均点赞约 0.59 万、平均收藏约 0.50 万，显著高于其他三词。
3. **收藏高于点赞**：全量收藏 24.2 万 > 点赞 21.0 万，说明内容「可收藏性」强（工具/方法论类）。
4. **评论互动极度长尾**：评论获赞中位数为 1，最高 2.9 万，符合社媒典型幂律分布。
5. **点赞与评论正相关**（r≈0.68）：高赞笔记往往也引发更多讨论，但离群点显示部分高热内容讨论不足。

## 五、代码与运行

脚本：`xhs_visualize.py`（已封装 8 个绘图函数，含中文字体配置与数值清洗）。

```bash
# 依赖（隔离环境已安装 pandas / matplotlib / numpy）
pip install pandas matplotlib numpy

# 直接运行（脚本与 data/ 目录同级）
python xhs_visualize.py
```

- 数据路径、输出路径集中在脚本顶部常量 `BASE / CONTENT_FILE / COMMENT_FILE / OUT_DIR`，改动只需调整这几处。
- 每次运行会重新生成 8 张 PNG 到 `output_xhs_viz/`。
